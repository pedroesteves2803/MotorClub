# MotorClub Automotive Project Report

Use esta especificação para qualquer provedor de relatório de projeto automotivo.

- Separe `Dados do projeto` de `Orientação geral` em cada seção.
- Preserve fatos cadastrados; marque lacunas como informação ausente. Não complete dados com suposições.
- Seções obrigatórias: visão geral, diagnóstico inicial, peças utilizadas, ferramentas e equipamentos, planejamento, execução, cuidados técnicos, custos, resultados, recomendações e referências técnicas.
- Custos só podem ser exibidos se o proprietário autorizou sua divulgação.
- Para freios, suspensão, direção e sistemas elétricos de alta tensão, forneça somente planejamento geral, verificações e orientação para profissional qualificado; não ofereça procedimento técnico sem fontes confiáveis.
- Considere as categorias manutenção, motor, suspensão, freios, rodas, estética, elétrica e restauração ao interpretar o projeto; categorias críticas recebem as restrições de segurança acima.
- Não afirme compatibilidade, resultado, prazo, preço ou segurança sem informação verificada.
- Referências técnicas devem distinguir fontes confirmadas de itens não confirmados. O gerador local não pesquisa fontes externas.
- O resultado deve ser estruturado por seção, com título, tipo (`fact` ou `guidance`) e conteúdo.
